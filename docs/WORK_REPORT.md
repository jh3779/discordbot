# Discord Text RPG 봇 작업 내용 보고서 (2026-05-27)

## 1) 이번 라운드 목표
- 기존 구현 상태를 기준으로, 현재까지 완료된 기능을 위험도 중심으로 정리
- 다음 개발 라운드에서 바로 실행 가능한 전체 작업 지시서와 진행도 추적 체계 수립

## 2) 현재 코드 기준 완료 내역 요약

### 데이터/무결성
- `users`, `characters`, `cooldowns`, `battle_logs`, `auto_delete_rules`, `tracked_messages` 테이블 생성됨.
- `characters`는 `(user_id, guild_id)` 유니크 제약으로 길드별 1캐릭터 정책이 반영됨.
- `items`, `user_items` 테이블과 `(character_id, item_id)` 유니크 제약으로 인벤토리 누적 저장 가능.

### 게임 루프
- `/rpg 시작` 캐릭터 생성 로직 구현됨.
- `/rpg 탐험`에서 쿨타임 확인, 이벤트 결정, 전투/보상/레벨 반영 흐름 구현됨.
- 전투는 자동 턴제, 최대 20턴, 승/패/무 처리 및 보상 지급 구현됨.
- 레벨업 공식(`level * 100`)과 스탯 증가 규칙 반영됨.

### 아이템
- 기본 아이템 시드 로직 존재.
- 탐험 아이템 이벤트 및 전투 드랍 아이템이 `user_items`에 누적 저장됨.
- `/rpg 인벤토리` 백엔드 조회 함수 구현됨.

### 운영 기능
- 자동삭제 트래킹/삭제대상 조회/성공·실패 상태 기록 로직 구현됨.
- 랭킹은 길드 단위로 `level DESC, exp DESC, updated_at ASC` 정렬.

## 3) 리스크 및 보완 필요사항
- 명령어 레이어(실제 Discord slash command 바인딩) 부재
- 자동삭제 스케줄러 실행 루프 및 Discord API 연동 미구현
- 테스트 코드 부재(현재는 `node --check` 위주)
- 마이그레이션 전략 부재(스키마 변경 시 운영 DB 대응)
- 전투/탐험 밸런스 검증 데이터(시뮬레이션) 부재

## 4) 다음 라운드 권장 착수 순서
1. 테스트 우선: 핵심 시스템 단위 테스트 추가
2. Discord 명령 바인딩 + 응답 포매터 구현
3. 자동삭제 워커 스케줄러 + 장애 처리
4. 관리자 명령(`/admin-rpg 삭제설정/삭제상태`) 최소 버전 구현
5. 밸런스 점검용 시뮬레이션 스크립트 작성

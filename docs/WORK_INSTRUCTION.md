# Discord Text RPG 봇 전체 작업 지시서 + 진행도 체크

## A. 작업 원칙
- 위험도 높은 영역부터 처리: **무결성 > 동시성 > 운영 안정성 > UX**
- 모든 기능은 “DB 반영 + 실패 케이스 + 테스트” 3요소를 함께 완료 처리
- 완료 정의(DoD):
  - 코드 반영
  - 최소 테스트 통과
  - 문서 체크리스트 업데이트
